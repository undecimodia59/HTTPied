# UI audit for the requested cleanup

This review covers HTTPied's native interface. It is a design review, not an objective
classifier for whether an interface was generated by AI.

The review used the original [no-slop-ui design guidance](https://github.com/LeoStehlik/no-slop-ui)
and [Design for AI principles](https://design.yaps.ai/docs/principles) as reference points.
They describe recurring generic patterns such as decorative badges, oversized repeated cards,
visual effects without a task purpose, and vague copy. The changes below address patterns
actually present in this application.

| Finding | Change |
| --- | --- |
| Decorative H / branding and pill statuses | Plain application title and compact status text |
| Repeated rounded containers, strong teal tint and selected-row accent bars | Flat neutral panels, thin separators, ordinary selection fill; syntax colors carry meaning |
| Oversized tabs and large gaps | Compact tabs, controls and spacing suited to request inspection |
| Tutorial/hero-style empty states | Short state descriptions: no captures, interception off, waiting for request |
| Synthetic 100k rows in the product interface | Removed the runtime control, state and rendering branch |
| Dummy local destinations and prefilled sample payloads | Empty destination/wordlist inputs; Browser starts at about:blank |
| Recent-run cards and request-snapshot section | Removed; stable per-request native text editor undo/redo |
| Multiple paragraphs repeating how each view works | Kept necessary transport/operation details in contextual help and the guide |

The top-level Intercept / History / Replay / Intruder / Browser tabs remain because they are
explicitly requested and support distinct tasks. Request/response panes remain framed for
selection and separation. There are no decorative gradients, fabricated metrics or fake
workflow buttons. The standalone benchmark example remains a developer artifact, outside
the application interface.

Reviewed native screenshots: `revision-highlight.png`, `revision-sort.png`,
`revision-numbers.png`, `revision-wordlist.png`. Aesthetic feedback on density, contrast and
platform-native expectations is still useful; no claim of universally removing every
possible "AI signature" is made.
