## Findings and changes

| Priority | Finding | Change and evidence |
| --- | --- | --- |
| High | Temporary projects used recursive directory creation, which accepted existing directories/symlinks; orderly shutdown recursively removes a temporary project's directory. | Require exclusive, nonrecursive creation of temporary project directories with Unix mode 0700. A collision now fails before opening a database or generating a CA. Regression covers existing directories and a Unix symlink. |
| High | Redacted exports/cURL retained URL query credentials; cURL also expanded secret variables into arbitrary custom headers. | Shared URL/header redaction covers complete queries, fragments, userinfo, common authentication/API-key fields, Referer and redirect locations. Secret variables are masked before redacted cURL expansion. JSONL/HAR representations, raw message copies and WebSocket target/payload redaction are covered. |
| Medium | Export files inherited the user's umask, potentially exposing captured credentials in a shared directory. | Capture and result exports use create-new files with mode 0600 on Unix. Existing-file protection remains. Regression checks JSONL/HAR permissions and non-overwrite behavior. |
| Medium | History applied a second label-only search after the common HistoryFilter match, hiding valid MIME and long-URL matches. | Use a single common filter with the current search text for live and saved rows; regression covers MIME matching and stale saved query state. |
| Medium | Saved History rows offered no transfer action until their bodies had been opened. | Context actions asynchronously fetch the clicked capture by ID and load it into Replay/Intruder. The clicked row need not be selected. A regression covers delayed/mismatched detail replies. |
| Medium | Failed Replay runs left old response bytes, allowing a view switch to resurrect a previous result. | Clear all response representations/target metadata on accepted sends, replacement and failure. Empty responses remain empty in every view. Regression drives an actual failed ResultEvent and checks all five view modes. |
| Medium | Find's selection lost focus to its toolbar click, so Next match did not leave copyable selected text. | Apply the requested selection after the editor processes the click. A mouse-event regression checks Unicode selection, focus retention and Copy output. This also fixes History's existing Find control. |
| Low | Primary History actions were hidden in context menus; paging and operation feedback were hard to interpret. | Visible Send to Replay/Intruder controls beside selection metadata, Copy URL in the context menu, matching range/total counts, loading indicator, useful empty-state guidance and three-second copy/loading feedback in the footer. |
| Low | Replay response Find only counted matches. | Add Next match/Enter navigation with selection and scrolling, and wrap the destination/control row at narrow widths. |
| Low | Clear view retained old decoding notices; Draft match counts used the captured text; Compare's “Set right side and compare” did not compute a diff. | Clear preview metadata, count Draft matches against the draft, and share comparison computation with the action. Draft comparison actions use draft text. |

Redacted exports omit obsolete folded header continuations and remove body framing/encoding
headers because the exported body is replaced. Captured project data and ordinary exports
remain independent of these redacted copies. No dependencies or schema changes were added.
